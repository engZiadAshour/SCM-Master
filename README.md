# SCM – Supply Chain Management System

## Project Overview
SCM is a collaborative Supply Chain Management project developed by multiple specialized teams.

The project integrates software engineering, artificial intelligence, data analysis, and distributed systems to build a comprehensive solution.

## Project Teams & Repositories

| Team | Repository |
|---|---|
| Backend & Database | SCM-Backend-Database |
| Data Analysis | SCM-Data-Analysis |
| Distributed Systems | SCM-Distributed-System |
| AI & Computer Vision | SCM-AI-Computer-Vision |
| Mobile Application | SCM-Mobile-App |
| AI Agents & LLMs | SCM-AI-Agents-LLMs |

## Project Structure
Each team maintains its own independent repository, while this repository serves as the central hub for all SCM subprojects.

## Collaboration
Each team is responsible for developing, maintaining, and documenting its assigned module.
